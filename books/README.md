# 📖 كتب المواد (صفحات حقيقية)

هذا المجلد يخزّن **صور صفحات الكتب الحقيقية** لكل مادة، ويتم عرضها داخل التطبيق في:

1. **لوحة المادة**: زر «الكتاب» يعرض الكتاب كاملاً (كل صفحات المادة من أقل بداية لأعلى نهاية عبر دروسها).
2. **مشغّل الدرس**: شريط صور صفحات الدرس (نطاق `pageRange`).

## تسمية الملفات

كل صورة تُسمّى برقم الصفحة (بدون أصفار بادئة):
```
books/<subjectId>/<pageNumber>.png
```

مثال: `books/arabic/4.png`, `books/arabic/5.png`, … `books/arabic/12.png`

## كيف أضيف الصفحات؟

### 1) مجلد صور جاهزة
ضع الصور بأي ترتيب (يُرتب حسب الاسم) ثم شغّل:

```
node prepare-books.js <subjectId> <مجلد_الصور>
```

مثال: `node prepare-books.js arabic C:\scans\arabic\`

- يقبل الصور `png / jpg / jpeg / webp` ويحوّلها إلى `PNG` في `books/arabic/`.
- أسماء الملفات تُرتب رقمياً (مثل `page04`, `page_4`, `4 a`) ويُستخدم **ترتيب الملفات ذاته** كأرقام صفحات، أو رقم الصفحة المكتوب في اسم الملف إن وُجد (مثل `page 12.png` → `12.png`).
- إن كان الملف `PDF`، تتم محاولة تحويله صورة-صورة عبر `pdfjs-dist` (يتطلب `npm i pdfjs-dist @napi-rs/canvas`).

### 2) عدم توفر صور بعد
الصفحات غير الموجودة تُعرض كبطاقة «📄 صفحة N» فارغة حتى تُضاف الصورة — وعند إضافة صورة، تُستبدل البطاقة بالصفحة الحقيقية تلقائياً. لا ينكسر شيء نتيجة الصور الناقصة.

## ملاحظة للحجم
صوّر كل صفحة بدقة معقولة (~1200-1600px عرض). المجلد يدخل في التطبيق مباشرة (دُفعه ديناميكية).
